# Simon-Says Game
A traditional Simon Says style of memory game, all built in HTML, CSS, and JS, but runs totally in your web browser. Your memory will be challenged by an continually increasing train of colours that must be repeated back in sequence. It's a lightweight, addictive exercise for your reaction time and your focus.
# Tech Stack used
It's built through basic front-end web technologies such that learning it is simple yet effective in exhibiting core programming skills. Main technologies utilized are:
-HTML5 for building the page structure and elements.
-CSS3 for styling and making the UI look awesome.
-JavaScript (Vanilla) for interactivity, logic, and gameplay functionality additions.
# Features
There are a number of core but essential features in this Simon Says game that lead to fun gameplay. It generates color sequences randomly, increases difficulty at each level, and also grants instant visual feedback. It also tells players when they have guessed incorrectly and they can also restart the game at will by pressing a key
# Further Improvments
Some of the ideas that can enhance the game further are adding sound effects upon button click initiations, enhancing mobile-friendliness in the layout, and implementing a high score counter. Other future updates can also involve adding user authentication, customizable themes, and animation effects that will enhance flow in gameplay and make it more dynamic.
